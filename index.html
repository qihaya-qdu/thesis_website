Abstract

Long-horizon decision making by large language model (LLM) agents becomes especially difficult in tasks with irreversible resource constraints, where locally reasonable actions may still be globally harmful. This thesis studies this problem in a simplified Mota-style dungeon environment, in which keys, doors and floor transitions create long-term dependencies.

A series of agent architectures is compared, progressing from local action scoring to explicit subgoal chains and programmatic verification. In the autonomous planning configuration, the LLM generates a subgoal chain and proposes the next target, while breadth-first search (BFS) checks target reachability before execution. An advanced version adds resource-lock detection, resets and reflection lessons. The experiments examine goal drift, resource-planning failures and the limits of autonomous LLM planning.

Introduction

An agent may identify the correct long-term objective yet fail to follow it during execution. In the Mota environment, opening a nearby door can appear useful while consuming a key needed for a later critical door. The consequences may only become visible many decisions later.

This study removes combat and retains the key, door and staircase dependencies. The environment is deterministic and fully observable, allowing planning errors to be examined through decision traces and resource budgets.

Method

Subgoal chains

A subgoal chain connects the final objective to intermediate resources, doors and floor transitions. The study develops three generations: action scoring; program-constructed dependency chains with LLM route selection; and LLM-constructed chains with programmatic target verification.

Programmatic verification

The LLM proposes a primary target based on the current state and its subgoal chain. BFS then checks whether the target is reachable. Rejected targets lead to further planning attempts. This check validates the next target's reachability, rather than the correctness of the complete chain.

Reset and reflection

The advanced configuration detects unwinnable resource locks, supports resets and records textual lessons from failures. These lessons are included in later planning prompts. The experiments compare this configuration with the base LLM-planning architecture.

Experiments

The quantitative experiments evaluate agent configurations across language models on five-floor and seven-floor maps. Success requires reaching the final goal. Early action-scoring agents are examined separately through qualitative interaction traces.

The program-guided architecture achieved higher success on the five-floor task. Moving dependency construction to the LLM made the planning task substantially harder. On five floors, the advanced configuration did not improve the success count; on seven floors, it achieved one additional success and a lower average runtime.

Limitations

These comparisons use small samples. The maps differ in layout and dependency structure as well as floor count. Invalid JSON and cloud-service failures affect some cross-model results. Reset and reflection were not isolated in a dedicated ablation, and successful advanced runs did not always use recovery mechanisms.

Conclusion

Explicit subgoal chains provide a persistent representation of task dependencies. BFS verification rejects unreachable targets, while resource-lock detection identifies states that can no longer lead to success. Reflection shows mixed benefits across the evaluated tasks. Further work is needed to test larger and more varied maps, partial observability and systematic measures of goal drift.
